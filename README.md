# FocusNudge

An Android app designed to break short-form video doomscrolling (YouTube Shorts, Instagram Reels, TikTok) using context-aware prompts and friction gates.

## Features
- **Role-Based Personas:** Customized nudges for Students, Professionals, Educators, and Custom roles.
- **Active App Detection:** Tracks active watch time using Android Accessibility Services.
- **Friction Gates:** Overlay timers and math challenges to interrupt mindless scrolling.
